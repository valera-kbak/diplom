# Учебный проект по HTML

**Автор:** Вельш Артём Николаевич  
**Дата создания:** 2023-11-15  
**Цель проекта:** Обучить основам HTML через практические примеры.

## 🛠️ Реализованные возможности:

1. **Базовые HTML-теги**:
   - Создана структура HTML-документа
   - Добавлены заголовки, параграфы, списки
   - Реализованы ссылки и изображения

2. **HTML-формы**:
   - Создана форма регистрации
   - Добавлены различные типы полей ввода
   - Реализована валидация форм

3. **Таблицы**:
   - Создана таблица с расписанием занятий
   - Добавлены объединенные ячейки
   - Стилизация таблицы через CSS
