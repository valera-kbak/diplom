🎨 Основы HTML

Что такое HTML?

HTML (HyperText Markup Language) — это язык разметки, который используется для создания структуры веб-страниц. Он состоит из тегов, которые определяют, как будет отображаться контент.

<!DOCTYPE html>
<html lang="ru">
<head>
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый HTML-документ.</p>
</body>
</html>

✨ Стилизация с CSS

Подключение CSS

Есть три способа добавить стили:

<!-- Внутренние стили -->
<style>
    body { background: #f0f0f0; }
</style>

<!-- Внешний файл -->
<link rel="stylesheet" href="style.css">

<!-- Инлайн стили -->
<div style="color: red;">Текст</div>

Селекторы CSS

/* По тегу */
p { color: blue; }

/* По классу */
.highlight { background: yellow; }

/* По ID */
#header { font-size: 2rem; }

/* По атрибуту */
input[type="text"] { border: 1px solid #ccc; }
